# Politique de Sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans LockState, **ne l'ouvrez pas publiquement** sur les issues.

### Contactez-nous en privé

1. Envoyez un email détaillé à : **[À COMPLÉTER : votre email]**
2. Incluez :
   - Description de la vulnérabilité
   - Étapes pour reproduire
   - Impact potentiel
   - Une proposition de correctif si possible

### Processus de traitement

1. Nous accuserons réception dans les **48 heures**
2. Nous travaillerons sur un correctif
3. Nous vous tiendrons informé de la progression
4. Une mise à jour de sécurité sera publiée dès que possible
5. Vous serez crédité dans le changelog (optionnel)
