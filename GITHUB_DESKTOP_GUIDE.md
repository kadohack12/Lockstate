# Initialiser avec GitHub Desktop

## ✅ Étapes simples

### 1️⃣ Ouvrir GitHub Desktop

Clique sur **File** → **Add Local Repository**

### 2️⃣ Sélectionner le dossier LockState

```
C:\Users\KADOHACK12\Documents\securisation opt\Lockstate
```

GitHub Desktop va :
- ✓ Initialiser Git automatiquement
- ✓ Créer le `.git/`
- ✓ Reconnaître tous les fichiers

### 3️⃣ Commit initial

1. Dans GitHub Desktop, tu verras tous les fichiers en **Changes**
2. Écris le message : `Initial commit: LockState security audit tool`
3. Clique **Commit to main**

### 4️⃣ Publier sur GitHub

1. Clique **Publish repository**
2. Entre le nom : `lockstate`
3. Description : `Local security audit tool - zero dependencies`
4. Sélectionne **Public**
5. Clique **Publish Repository**

## 🎯 Résultat final

Ton repo sera sur : **https://github.com/kadohack12/lockstate**

## 🏷️ Ajouter un tag (v0.1.0)

Après le premier commit :
1. Va à **History**
2. Clique droit sur le commit → **Create Tag**
3. Nomme-le `v0.1.0`
4. Publie avec **Publish repository**
